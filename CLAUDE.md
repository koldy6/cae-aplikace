# CAE ENGLISH – PROJECT INSTRUCTIONS

Applies to work inside `projects/cae-english/`. Studio-wide rules are in the root `CLAUDE.md`.

## Project purpose
Build an excellent AI-powered application for preparing for Cambridge C1 Advanced (CAE).

## Main examination areas
- Reading and Use of English
- Writing
- Listening
- Speaking

## Additional learning features
- Grammar training
- Vocabulary building
- Practice exercises
- Full mock examinations
- Progress tracking
- Personalized AI tutoring
- Performance analysis

## Language
- Explain concepts in Czech when helpful.
- Use English for examination exercises and practice.
- Gradually adapt the difficulty to C1 Advanced level.

## Educational accuracy
- Follow the official Cambridge C1 Advanced examination format.
- Use reliable educational sources.
- Distinguish official examination requirements from practice exercises created by AI.
- Never invent official Cambridge questions or claim that unofficial exercises are official.
- Explain mistakes and provide useful corrections.
